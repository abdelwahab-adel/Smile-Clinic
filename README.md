# سمايل كلينيك — نسخة HTML / CSS / JavaScript

موقع عيادة **سمايل كلينيك** (طب وتجميل الأسنان) مبني بالكامل باستخدام **HTML5 دلالي (Semantic)**،
**CSS3** مخصص بدون أي إطار عمل (بدون Tailwind / Bootstrap)، و **Vanilla JavaScript (ES6+)** بدون أي
مكتبة أو Framework. هذه النسخة تحويل تقني كامل لمشروع كان مبنيًا أصلاً بـ React + TanStack Router +
Tailwind CSS، مع الحفاظ الكامل على المحتوى، التصميم، الـ Layout، والتفاعلات.

## المتطلبات التقنية

- لا React / Vue / Angular
- لا TypeScript / JSX
- لا Tailwind / Bootstrap
- HTML5 + CSS3 + JavaScript ES6+ فقط، بدون أي أدوات بناء (Build Tools) — الموقع يعمل مباشرة بفتح
  `index.html` أو تشغيله على أي خادم استاتيكي.

## هيكل الملفات

```text
project/
├── index.html              # الصفحة الرئيسية (Single Page مع كل الأقسام)
├── 404.html                 # صفحة الخطأ 404
├── css/
│   ├── style.css            # المتغيرات (Design Tokens) + Reset + Typography + تخطيط عام
│   ├── components.css       # تنسيقات كل عنصر: الهيدر، الأزرار، الكروت، الفورم، الأكورديون...
│   └── responsive.css       # نقاط التوقف (Breakpoints): 640px / 768px / 1024px
├── js/
│   ├── app.js                 # الملف الفعلي المُحمَّل في index.html — حزمة واحدة (bundle) بدون
│   │                           #   import/export، عشان الموقع يشتغل بفتح index.html مباشرة (file://)
│   │                           #   من غير أي سيرفر. لو عدّلت أي ملف من التالت اللي تحت، لازم تعيد
│   │                           #   تجميعه (concatenate) في app.js يدويًا (بترتيب: data → components →
│   │                           #   home → main، مع حذف أسطر import/export).
│   ├── main.js                 # (مصدر) نقطة الدخول — يهيّئ كل المكونات عند تحميل الصفحة
│   ├── components.js           # (مصدر) سلوك المكونات المشتركة: الهيدر، القائمة، الأكورديون، معرض الصور
│   ├── data/
│   │   └── blog-articles.js    # (مصدر) نص المقالات الكاملة لمودال المدونة
│   └── pages/
│       └── home.js             # (مصدر) منطق نموذج الحجز الخاص بالصفحة الرئيسية (تحقق + إرسال)
├── assets/
│   ├── icons/
│   │   └── sprite.svg        # نفس أيقونات Lucide، مُضمَّنة (inline) أيضًا داخل index.html نفسه
│   │                         #   مباشرة بعد <body> — لأن <use href="sprite.svg#icon-x"> بيتمنع في
│   │                         #   بعض المتصفحات لما تفتح الصفحة بـ file://. الملف هنا محتفظ بيه كمرجع.
│   └── images/
│       └── favicon.ico
└── README.md
```

> **ملاحظة مهمة عن التشغيل بدون سيرفر:** الموقع مُجهَّز عشان يشتغل بالكامل بفتح `index.html` بدبل
> كليك، من غير أي سيرفر محلي. ده معناه إن سكريبت `js/app.js` مكتوب كسكريبت عادي (مش ES Module)،
> وأيقونات `sprite.svg` مُضمَّنة (inlined) جوه الـ HTML نفسه. لو حبيت ترجع لهيكلة الملفات المنفصلة
> (import/export) في التطوير، تقدر تشغّل أي سيرفر استاتيكي بسيط وترجّع `<script type="module"
> src="js/main.js">` بدل `js/app.js`.

> **ملاحظة حول الصفحات:** المشروع الأصلي كان تطبيق صفحة واحدة (Single Page Application) بقسم واحد
> فقط (`/`) تتنقّل فيه كل الروابط عبر مراسي داخلية (`#about`, `#services`, `#contact`, ...). للحفاظ
> على نفس التجربة والروابط بالضبط، تم الإبقاء على هذا التصميم في `index.html` بدل تقسيمه إلى ملفات
> منفصلة كان سيغيّر سلوك التنقل الأصلي.

## طريقة التشغيل

لا حاجة لأي تثبيت أو بناء، ولا لأي سيرفر:

1. افتح `index.html` بدبل كليك من جهازك — الموقع يعمل بكل مميزاته فورًا (JavaScript وكل الأيقونات
   شغالة من غير سيرفر)، **أو**
2. لو بتفضّل التطوير بالملفات المنفصلة (ES Modules)، شغّل أي خادم استاتيكي محلي، مثال:

   ```bash
   python3 -m http.server 8000
   # ثم افتح http://localhost:8000
   ```

## الوظائف المُنفَّذة في JavaScript

| الوظيفة | الوصف | الملف |
|---|---|---|
| ظل الهيدر عند التمرير | إضافة حدّ وظل خفيف للهيدر بعد تمرير الصفحة | `js/app.js` |
| القائمة المتنقلة (Mobile Menu) | فتح/إغلاق قائمة الجوال مع تبديل أيقونة Menu/X | `js/app.js` |
| تمييز الرابط النشط (Scroll Spy) | تمييز رابط القسم الظاهر حاليًا باستخدام `IntersectionObserver` | `js/app.js` |
| الأكورديون (الأسئلة الشائعة) | فتح سؤال واحد فقط في كل مرة (Single-open) مع حركة انتقالية | `js/app.js` |
| معرض الصور (Lightbox) | تكبير الصورة عند الضغط عليها، إغلاق بالنقر خارجها أو زر Escape | `js/app.js` |
| مودال المقال (Blog) | الضغط على أي بطاقة مقال في المدونة يفتح نافذة تعرض المقال كاملاً، مع إغلاق بالزر أو النقر خارجها أو Escape | `js/app.js` |
| زر العودة للأعلى | يظهر بعد تمرير 400px وينفّذ تمريرًا سلسًا للأعلى | `js/app.js` |
| مقارنة قبل/بعد بالسحب | شريط تمرير تفاعلي (Drag to Compare) لكل حالة، مبني على `<input type="range">` لدعم اللمس ولوحة المفاتيح تلقائيًا | `js/app.js` |
| تصفية نتائج قبل/بعد | أزرار تصنيف (الكل / هوليود سمايل / تبييض / زراعة) تُظهر أو تُخفي البطاقات المطابقة | `js/app.js` |
| نموذج الحجز | تحقق من الاسم ورقم الهاتف، رسائل خطأ، حالة تحميل، رسالة نجاح | `js/pages/home.js` |

جميع ملفات JavaScript مكتوبة كوحدات ES Modules (`type="module"`) ويتم تحميلها بشكل مؤجَّل تلقائيًا.

## هيكل CSS

- **`style.css`**: يحتوي على كل متغيرات التصميم (`--color-*`, `--radius-*`, الخطوط...) في `:root`،
  بالإضافة إلى الـ Reset، الطباعة الأساسية (Typography)، وحركة الدخول (`.rise`).
- **`components.css`**: كل الأنماط الخاصة بمكوّن معيّن (هيدر، هيرو، كروت الخدمات، الأسعار، الفورم،
  الفوتر...)، بأسماء Classes واضحة بنمط شبيه بـ BEM (مثال: `.pricing-card__feature`).
- **`responsive.css`**: كل الفروقات بين أحجام الشاشات فقط، مبنية على `min-width` بنفس نقاط التوقف
  التي كانت مستخدمة أصلاً (`sm: 640px`, `md: 768px`, `lg: 1024px`).

الألوان معرّفة بصيغة `oklch()` (معيار CSS Color Module 4) كما في التصميم الأصلي، مع استخدام
`color-mix()` لأي شفافية (بدل صيغ غير مدعومة بشكل واسع).

## إمكانية الوصول (Accessibility)

- عناصر HTML5 دلالية: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<article>`, `<aside>`.
- رابط "تخطَّ إلى المحتوى الرئيسي" (Skip to content) يظهر عند التنقل بلوحة المفاتيح.
- `alt` واضح لكل الصور، و `aria-label` لكل زر أيقونة بدون نص مرئي.
- `aria-expanded` / `aria-controls` على القائمة المتنقلة وأزرار الأكورديون.
- `aria-invalid` + رسائل خطأ مرتبطة بحقول النموذج عند فشل التحقق.
- تباين ألوان وحلقة تركيز (Focus Ring) واضحة عند التنقل بلوحة المفاتيح.

## ملاحظات

- شريط مقارنة "قبل/بعد" يعتمد على اتجاه ثابت (يسار→يمين) بغض النظر عن اتجاه الصفحة (RTL)، لأنه عنصر
  بصري/مكاني (مقارنة صورتين) وليس محتوى نصيًا، وهذا يطابق سلوك مكونات المقارنة المشابهة في أغلب
  المواقع بصرف النظر عن لغة الواجهة.
- الأيقونات مبنية على مجموعة [Lucide](https://lucide.dev) (رخصة ISC) وموجودة كملف SVG Sprite واحد
  في `assets/icons/sprite.svg` لتقليل الطلبات وتسهيل إعادة الاستخدام.
- روابط الصور (Unsplash) وخرائط Google مأخوذة كما هي من المشروع الأصلي دون أي تغيير.
- الخطوط (`Cairo` و `Tajawal`) محمّلة من Google Fonts بنفس الأوزان المستخدمة أصلاً.
